参加する

VIVA-MCの世界へようこそ。接続の手順と必要な情報をまとめています。

あなたに合った入り方

遊ぶ機種をえらぶと、その機種での入り方だけを表示します。

パソコン（Java版）での入り方

  1. Minecraft Java Edition を 26.2 で起動します。
  2. タイトル画面で「マルチプレイ」→「サーバーを追加」を選びます。
  3. 「サーバーアドレス」に を入れます（ポートの入力はいりません）。
  4. 「完了」を押し、一覧に出た VIVA-MC を選んで「サーバーに接続」。

「サーバーリソースパック」は 有効 にしておくと、乗り物などがきれいに表示されます。

スマホ・タブレット（統合版）での入り方

  1. Minecraft を最新版に更新して起動し、「遊ぶ」を押します。
  2. 上のタブから「サーバー」を開き、いちばん下の「サーバーを追加」を押します。
  3. サーバー名に VIVA-MC、アドレスに 、ポートに 19132 を入れます。
  4. 「保存」を押し、一覧の VIVA-MC から接続します。

アドレスは長押しで貼り付けられます。上のボタンを押すとコピーできます。

Windows（統合版）での入り方

  1. Minecraft（統合版）を最新版に更新して起動し、「遊ぶ」を押します。
  2. 「サーバー」タブを開き、「サーバーを追加」を押します。
  3. サーバー名に VIVA-MC、アドレスに 、ポートに 19132 を入れます。
  4. 「保存」を押し、一覧の VIVA-MC から接続します。

「Java Edition」のアイコンの方を使っている人は、パソコン（Java版）の手順を見てください。

Switch・PS・Xbox での入り方

ゲーム機版の Minecraft は、メニューから外部のサーバーを追加できないようになっています。入るには、ゲーム機のネット設定を変えるなど、ひと手間かかります。

手順は機種によって違い、ときどき変わるので、Discordで機種名を伝えてください。いま使える方法を案内します。

Discordで入り方を聞く

入れなかったときは、サーバーの様子で開いているかを確かめるか、臨時アドレスが出ていないか見てください。

接続までの手順

上から順に進めれば入れます。

  1. 1

    バージョンを確認する

    Java版・統合版（Bedrock）のどちらからでも参加できます。最新の安定版を使ってください。

  2. 2

    サーバーを追加する

    マルチプレイ画面で「サーバーを追加」を選び、下の接続先を入力します。

  3. 3

    入国したら、まず町へ

    いきなり建国しなくて大丈夫です。まずは既にある町に参加して、通貨の稼ぎ方と土地の仕組みに慣れましょう。

  4. 4

    自分の国をつくる

    資金と仲間が集まったら建国できます。憲法や法律を定め、外交や貿易を始めましょう。

接続先

アドレスは押すとコピーできます。

つながらないときは

お知らせで「アドレス変更」と告知されている場合、通常のアドレスでは入れません。臨時アドレスの一番上を確認してください。

## 1. 丸ごと元に戻したいとき

GitHubの画面だけで戻せます。

1. リポジトリの **Pull requests** → **Closed** を開く
2. 戻したいところまでの PR を開く
3. 右下の **Revert** ボタンを押す
4. 出てきた新しい PR を **Merge** する

これで、その PR の変更だけが取り消されます。新しく PR が作られる形なので、
間違えたらさらに Revert し直せます。**履歴は消えません。**

## 4. 一部だけ元に戻したいとき

たとえば「木の見た目だけ元に戻したい」など。

- **木の色を変えたい** … `style.css` の上のほうにある `--wood-oak` 〜 `--wood-dark-oak` を直す
- **木の種類を変えたい** … HTMLの `class="faq birch"` の `birch` を消す、または
  `oak` / `spruce` / `acacia` / `cherry` / `dark-oak` に書き換える
- **動きを消したい** … `script.js` の「スクロールで板をふわっと出す」の
  かたまりを消すか、`style.css` の「動き（控えめに）」のかたまりを消す
- **資源ワールドのリセット日を変えたい** … `script.js` の `RESET_DAY` の数字を変える

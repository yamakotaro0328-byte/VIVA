# 英語のページ（/en/）の作り方

日本語のページ（ルートの `*.html`）から、英語のページを自動で作る。

```
python3 tools/i18n/build_en.py
```

- 訳は `en.json`（日本語の文 → 英語の文）。日本語のページを書き換えたら、もう一度実行する
- 訳の無い文があると、その文の一覧を出して止まる。`en.json` に足してから実行し直す
- 画面で動く文字（ランキングや年表など）は `live.js` と `script.js` の中で `L('日本語', 'English')` の形で書く
- このフォルダはサイトとしては公開しない（`.vercelignore`）

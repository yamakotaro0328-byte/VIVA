about report

通報機能について

利用規約に反しているプレイヤーを見つけた時

コマンド/r または/reportにより、プレイヤー追放投票を開けます

投票結果により、プレイヤーにはtmpban またはban を行います

最終的には運営が処罰内容を確定しますが、その際、判断しやすいようになるべくdisordにて写真の送信をよろしくお願いします

Core Mechanics

洗練された国家運営システム

独自の法制度の制定

建国したプレイヤーは、自国の領土内において「憲法」や「法律」を自由に定める権利を持ちます。

プレイヤー駆動型リアル経済

サーバー内独自の通貨制度とダイナミックに変動する市場システム。関税の設定や貿易ルートの確保が、国家の盛衰を左右します。

宣戦布告と外交条約

争いはルールに基づいて行われます。公式な「宣戦布告」手続きを経て、防衛側の同意またはシステム判定のもとで大規模な領土戦が勃発します。

Rules & Constitution

サーバーの規則

絶対に禁止されている行為

  • 不正クライアント・チート（Hackツール、X-Ray等）の使用
  • 領土内外における悪意ある荒らし行為・窃盗
  • リアルマネートレード (RMT) およびそれに準ずる外部取引
  • 暴言、誹謗中傷、プライバシーを侵害する発言
  • サーバーに過度な負荷をかける装置の作成・放置
  • その他、運営が迷惑行為と判断した行為

※サーバーに参加した時点で、本規約に同意したものとみなします。

Getting Started

参加方法・接続情報

サーバーへの参加手順

STEP 1: バージョンの確認

Minecraft Java版または統合版（Bedrock）で参加可能です。最新の安定版バージョンをご利用ください。

STEP 2: サーバーアドレスの追加

マルチプレイ画面で「サーバー追加」を選択し、以下の情報を入力してください。

接続先情報

  • IP: viva-mc.net
  • Java Port: 25565
  • 統合版(BE) Port: 19132

技術環境

WORLDGUARD

Build server

A separate server, away from the main one, for building freely. Protect your builds with WorldGuard.

Go to the build server

Run /server build to move to the build-only server. It's a separate world from the main server, so Lands (land protection), Jobs and similar systems don't work there. You can move back and forth any time with the /server command.

Protect with WorldGuard

Protect your builds so nobody else can grief them.

  1. 1

    Hold the selection tool

    Use the WorldEdit selection tool (wooden axe). If you don't have one, get it with //wand.

  2. 2

    Select two opposite corners

    With the wooden axe, left-click (first point) and right-click (second point) the two blocks at opposite corners of the area you want to protect.

  3. 3

    Protect it

    Run /rg define <region> to protect the whole selected area. You can choose any name you like.

Protection can fail if the area is too large or overlaps someone else's region. If /rg define doesn't work, try /rg claim. If it still doesn't work, ask on Discord.

Invite friends

You can add people you want to build with as members or owners.

/rg addmember <region> <player>Add as a member (can build with you)
/rg addowner <region> <player>Add as an owner (with stronger permissions, such as deleting the region)
/rg removemember <region> <player>Remove a member
/rg removeowner <region> <player>Remove as an owner

Check your regions

You can check the status of your regions any time.

/rg info <region>See details of a region (members, area and so on)
/rg listList your regions
/rg flag <region> <flag> <value>Change detailed settings (e.g. /rg flag <region> pvp deny to disable PvP)

Commands

//wandGet the selection tool (wooden axe)
/rg define <region>Protect the selected area
/rg addmember <region> <player>Add a member
/rg addowner <region> <player>Add an owner
/rg removemember <region> <player>Remove a member
/rg removeowner <region> <player>Remove an owner
/rg info <region>See region info
/rg listList your regions
/rg flag <region> <flag> <value>Change detailed settings

If a command doesn't work or you're not sure how to protect something, ask on Discord.
